# Runtime Overlays

Overlays are appendable governance snippets that can be stacked on top of base runtimes.

## Available overlays
- `sensitive-domain-overlay.snippet.txt`
- `live-demo-overlay.snippet.txt`

## How to use
1) Use your base runtime kernel (HNC + CCBP).
2) Append overlay snippet(s) verbatim.
3) Run `hnc-conformance` tests to validate behavior.
